# 第16课：收藏常用网站

经常用的网站，每次都要输网址太麻烦。可以把它"收藏"起来，下次一键打开。

---

## 怎么收藏一个网站

1. 打开你想收藏的网站（比如百度）
2. 按键盘上的 **Ctrl + D**
3. 弹出一个小窗口，点"完成"

这个网站就被收藏好了。

---

## 怎么打开收藏的网站

1. 点浏览器右上角的 **星星图标**（或者按 Ctrl + Shift + O）
2. 里面有你收藏的所有网站
3. 点一下名字，就直接打开了

就像你把常用的电话号码存到手机通讯录里，下次直接拨，不用每次都记号码。

---

## 小练习

1. 打开百度首页
2. 按 Ctrl + D，把它收藏起来
3. 关掉这个标签页
4. 点收藏夹里的百度，重新打开

收藏和打开收藏网站，就学会了。
