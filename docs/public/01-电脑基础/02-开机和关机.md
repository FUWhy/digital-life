# 第2课：开机和关机

## 开机

找到主机上的电源按钮，按一下。

电源按钮一般在主机正面或者上面，是最大的那个按钮，上面有个圆圈一竖的标志。

按一下之后，屏幕会先黑着，然后出现品牌标志，接着 Windows 开始加载。这个过程大概半分钟到一分钟，耐心等，不要反复按按钮。

> [!note] 显示器也要开
> 如果主机开了但屏幕一直黑，看看显示器的电源灯亮不亮。没亮的话按一下显示器上的电源按钮。

## 登录

如果你的电脑设置了密码，会出现一个登录界面。

在输入框里输入密码，按回车键，或者点箭头按钮，就能进入系统。

如果开机后直接进入桌面，说明没有密码，跳过这一步。

## 关机

用完电脑后，不要直接拔电源。正确的关机方式：

1. 点击左下角 **开始按钮**
2. 找到 **电源** 图标
3. 点击 **关机**
4. 等屏幕完全变黑，再关闭显示器电源

> [!warning] 不要直接按主机电源键关机
> 强制关机可能会丢失没保存的内容，下次开机也会变慢。
