# 第1课：从开机到认识桌面

## 开机

找到电脑主机上最大的那个电源按钮，按一下。

屏幕会先黑一会儿，然后出现品牌标志，接着 Windows 开始加载。这个过程大概需要半分钟到一分钟，**耐心等，不要反复按按钮**。

## 登录

如果你的电脑设置了密码，会出现一个登录界面。

在输入框里输入密码，按回车键，或者点击箭头按钮，就能进入系统。

> [!note] 没有密码？
> 如果开机后直接进入桌面，说明没有设置密码，跳过这一步即可。

## 进入桌面

等所有加载完成后，看到的这个画面，就是 **桌面**。

它就像你家里的书桌——上面放着常用的东西，下面是操作的台面。

![Windows 桌面布局示意图](../../assets/images/desktop-layout.png)

## 桌面的四个区域

### 开始按钮

屏幕左下角，那个像四格窗户的图标。

这是电脑的总入口——所有软件、设置、文件，都从这里开始找。

### 任务栏

屏幕最下面这一条横条。

正在用的软件、常用的软件，都放在这里。你可以在这上面切换窗口、看时间、找正在运行的程序。

### 桌面图标

桌面中间那些小图片，下面带着文字。

每个图标代表一个软件或者一个文件夹。就像书桌上贴的标签——看到标签就知道里面是什么。

新电脑桌面上图标很少，这是正常的，以后常用的软件会慢慢放上来。

### 通知区域

任务栏最右边，显示时间、音量、网络图标的地方。

这里显示电脑的状态：有没有连网、声音大小、现在几点。

## 关机

用完电脑后，不要直接拔电源。正确的关机方式：

1. 点击左下角 **开始按钮**
2. 找到 **电源** 图标
3. 点击 **关机**
4. 等屏幕完全变黑，再关闭显示器电源

> [!warning] 不要直接按电源键关机
> 强制关机可能会丢失未保存的内容，下次开机也会变慢。
