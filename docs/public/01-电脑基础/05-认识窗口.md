# 第5课：认识窗口——移动和调整大小

程序打开后出现的那个长方形画面，就叫 **窗口**。

![窗口操作说明](../../assets/images/window-operation.png)

## 怎么移动窗口

把鼠标移到窗口**最上面那一条蓝色横条**（叫标题栏）上，按住左键不放，拖动鼠标，窗口就跟着移动了。

移到你想放的位置，松开鼠标左键就行。

> [!tip] 就像拖动一张纸
> 移动窗口跟你用手在桌上推一张纸是一个道理——按住、拖动、松开。

## 怎么调整窗口大小

把鼠标移到窗口**的边缘或者角上**，鼠标箭头会变成双向箭头。这时候按住左键拖动，就能把窗口拉大或者缩小。

四个角拖起来最方便，可以同时调整宽和高。

## 怎么关闭窗口

点窗口右上角那个 **叉号（X）**，窗口就关了。

这个我们上一课已经用过了，这里再熟悉一下。

## 练习一下

1. 打开开始菜单，打开"计算器"
2. 把鼠标移到窗口顶部标题栏，按住左键拖动，把窗口移到屏幕中间
3. 把鼠标移到窗口右下角，等箭头变成双向后，拖动调整大小
4. 点叉号关闭
